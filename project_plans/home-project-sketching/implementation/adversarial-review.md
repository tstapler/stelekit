- Fix: (1) Before any commit, scrub `research/wiki-corpus-summary.md (private original out of repo)` and `requirements.md` (replace the address with `<home>`, names with `Owner-A/B`) or add `project_plans/home-project-sketching/` to `.git/info/exclude` and keep it local. (4) Add a CI grep test over `FIX/**` and `project_plans/home-project-sketching/**` for the street-number pattern and the household names.

### B2. ADR-006's default (option C) and its "small" option A are both unsupported by the actual writer code; Story 5.4 is not one-worker-run sized
- Evidence (VERIFIED, read in full):
  - `SpliceRequest` has only `insertions: List<BlockInsertion>` and `pageProperties` (MarkdownSplicer.kt:15-19). `BlockInsertion` is "LAST child" only.
  - `RoundTripGuard.verifyBytes` (RoundTripGuard.kt, last third) requires the original to be a subsequence of the output, both char-wise and line-wise. A replacement of an existing block fails this check by construction. `verifyStructure.sameBlock` and `verifyInserted` (expected = original tree plus appended blocks) also fail. So option A is not an "extension" of `SpliceRequest`; it needs a second verification mode in four functions plus `RoundTripGuard.probe`.
  - `TargetWriter` (TargetWriter.kt) has `write`, `deletePageFile`, `fileHash`, `removeBlocks`, `readExisting` and no replace. `ActiveTargetWriter.write` (lines 82-104) refuses with `ExistingContentChanged("merged page lost or altered an existing block")` whenever an existing block differs. So the active graph (the graph the post-sync hook runs against) also cannot overwrite our own digest page once the first digest exists. The first write works; the first regeneration with changed numbers is refused. Option C "rewrite whole page via GraphWriter" therefore needs new `TargetWriter` API on both writers, `RoutedTargetWriter`, `TargetWriterContractSuite`, and the `MergeUndo` manifest.
  - CLAUDE.md ("Off-graph writes only splice ... Never re-render an existing file") forbids option C's off-graph "replace-whole-file". ADR-006 does not record an amendment to that rule.
  - ADR-003's independence rule keys on a block carrying `stelekit-digest::`. Under option C the digest is a whole page; the marker location (page-level property bullet vs every block) and the extractor's page-level exclusion are unspecified.
- Impact: 5.4 (cost M) hides a cross-cutting change; 5.7, 7.1 and metric 3 (regeneration on sync) depend on it; the plan's own risk row 2 is "Medium until 5.1 decides" but the wave plan schedules 5.4 in W4 with fixed M sizing.
- Fix: Split 5.4 into 5.4a "TargetWriter.replaceOwnPage/ReplaceOwnBlock contract + both writers + contract-suite cases + guard verification mode (spec first)" and 5.4b "DigestWriter". Make 5.1's output a decision with file/line counts, then re-size. Add an ADR-006 amendment that explicitly scopes the CLAUDE.md exception: only blocks/pages with our marker, hash-checked (`fileHash`) before replace, via `GraphWriteLock`. Define the marker as page-level (first property bullet) for option C and update ADR-003 independence accordingly. Handle `Retryable(PageBeingEdited)` from `ActiveTargetWriter` (5.7 AC currently only says "failure never fails the sync").

### B3. Success metric 1 is not actually delivered by any story: no dimension-identity mapping, and the golden is fed by a test helper instead of the shipped extractors
- Evidence: Metric 1 says "importing the elevation + section + measurements table yields a fused model". Add a geometry-dimension extractor (or drop E-geom/S-geom from the expected source counts and the "15 dimensions with >=2 sources" claim). Add a `count` dimension kind or drop C5 from the golden.

## Top 3 findings
1. B1: the repository is public and the plan's confidentiality control covers only the fixtures; research, 7.2 quotes, and a slug derived from the page title would publish the home address and household names.
2. B2: ADR-006's default writer path cannot work with the current `RoundTripGuard`/`TargetWriter` API (verifyBytes subsequence rule, `ActiveTargetWriter` refuses altered blocks) and contradicts CLAUDE.md; Story 5.4 is under-sized and on the critical path of metric 3.

## Happy Path Scenario
Given the Baseline in `requirements.md` (Android phone, no adb, no in-app query tool, `asset_index` populated by nothing, `startPeriodicSync` with no production caller), when the owner turns on Developer mode and runs `sql select name from pages order by updated_at desc limit 3` in the console (or taps the `sql: newest journals` chip), then a grid with a header row, three rows and an OK chip appears, the database is unchanged (read-only engine-enforced handle), one audit line without secrets reaches the persisted Logs sink, and the same app composition (through `WiredAppFixture`) is the one that also starts the scheduled-sync loop and the asset stack, so the wired-feature catalog can prove each feature through its real composition root. Error paths (blocked write, 10 s timeout, developer mode off, graph closed mid-query) and the other subsystems are variations on this flow.

## Test Stack
- **Unit**: Kotlin `kotlin.test` `@Test` functions; `kotest-assertions-core` and `kotest-property` (`Arb`/`checkAll` inside `runTest`) for the tokenizer, `Redactor`, bypass-suite generation, drain terminal state and top-k tests (plain KMP libraries, not the Kotest runner); `kotlinx-coroutines-test` (`runTest`, `advanceTimeBy`) for every timer and loop; pytest for `scripts/ci/*.py`.
- **Integration**: real SQLDelight over `IN_MEMORY`/file DBs and a real `DatabaseWriteActor` (never mocked); `WiredAppFixture.android()` (Robolectric, `androidUnitTest`) and `WiredAppFixture.desktop()` (`jvmTest`) for composition-root entry points; Ktor `MockEngine` for Anthropic and Google; fake `FileSystem`, `Settings`, `LlmCredentialStore`, `ImageLabeler`, `PdfTextExtractor`, `TextRecognizer`, `NetworkMonitor`, `GitRepository`; JGit temp origin (`jvmTest`, desktop-only); WorkManager test driver; Pixel_Fold emulator via `./gradlew :kmp:connectedDebugAndroidTest -Pandroid.testInstrumentationRunnerArguments.class=<fqcn>` (read the result XML; no logcat).
- **E2E / UX**: Robolectric Compose tests for every UW criterion that is mechanically assertable; Playwright against the wasm build for the Web subset only (UW-02, UW-13); the owner device passes (plan Epic 12) for TalkBack, soft keyboard, charger, real network and 451 MB timing.
- **Bazel/Gradle**: `timeout 30m bazel test //kmp:business_tests` (recount the class total from the real run); `scripts/jvm-display-check.sh -- bazel test //kmp:jvm_tests ...` before trusting any `jvmTest` UI result; `./gradlew testDebugUnitTest` for AU; a bare `jvm_tests` UI failure is unverified, not a regression.
- **Additions from the plan patches**: `ObservableEffect.assert("<label>") { ... }` fixture helper (Task 1.1d) used by every catalog entry-point test; `FirstOpenSmokeTest` on the shipped `MainActivity` in `androidApp/src/test/kotlin` (Task 1.3c); `AssetPipelineHeapGateTest` on Pixel_Fold as the blocking Android heap gate (Task 5.2c); `business_test_data_as_resources` so `.txt` data files are visible under Bazel (Task 1.1c); fakes for `Settings` and `LlmCredentialStore` feed the real `CloudConsentGate` (no test mint path).
- **Flake rules (every new test)**: owned scope cancelled in teardown, virtual time via `runTest`, no `Thread.sleep`, no shared singleton state, no `@Ignore` or retry to turn red green without a stated root cause (enforced by `TestHygieneAuditTest`).

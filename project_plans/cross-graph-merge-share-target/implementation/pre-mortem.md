| 1 | The off-graph markdown write (ADR-001) passes Spike 0.1.1 on an in-memory `FakeFileSystem` fixture but misbehaves on real disks and platforms. | 2 | `RoundTripGuard` (`serialize(parse(file)) == file`) is too strict for real user files. Most off-graph writes return `NotRoundTrippable`. If it misses, decide "structure-stable" semantics for the guard now, since the splicer already preserves bytes. | P1 |
| 3 | The `GraphWriteLock` changes inside `GraphManager.switchGraph`'s init coroutine (Task 2.1.1c) introduce a deadlock or a stuck lock. Examples are a nested acquisition, `awaitPendingMigration()` under a lock, a migration that throws or hangs while holding `lock(id)`, or a double-close of a factory under rapid B-then-C switches. Graph switching or startup hangs app-wide on every platform, including for users who never use the copy feature. The plan gates this on a hot, 1 478-line class. | The app freezes on "loading graph" after a switch or startup. `GraphWriteLockTest` flakes under `withTimeout`. `merge.apply.lock_wait_ms` shows multi-second waits. | Ship the `GraphManager` lock edit as its own small PR before any merge code. Acquire the lock with a bounded wait (`withTimeout`) and release it in `finally`. On timeout, log and proceed without the merge, never block the open path. Run the stress test (rapid B-then-C switches, slow `DriverFactory`, paused migration) in CI on every platform. Make the lock-order assertion helper active in debug builds of production code, not only in tests. | P1 |

- [ ] Failure #2: Add Spike 0.1.4 to Phase 0: measure the `RoundTripGuard` pass rate over a real exported graph. Set a go/no-go threshold (for example 95%) and settle the guard strictness before Story 2.3.1. If it misses, change the guard to "structure-stable" before building the writers.
- [ ] Failure #3: Split Task 2.1.1c into a separate first PR. Use bounded lock acquisition (`withTimeout`) with release in `finally` and a degrade-open fallback, a lock-order assertion active in production debug builds, and a CI stress test (rapid switches, slow driver, paused migration, throwing migration) on all platforms. Merge nothing else that depends on it until that PR is green.
